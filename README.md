# 烈焰升騰：同島一命
- *當前版本：1.0.0 「國家、榮譽、責任」*

年曆翻至西元2020年。 世界正不安地躁動，美利堅的團結不再; 一種前所未聞的病毒正悄然蔓延; 日出之地還陷於失去的30年中。 烈焰正欲燃起。
福爾摩沙，這座小島正於風雨中飄搖。 臺灣曾歷經不少風雨。 四百餘年春秋，從荷蘭人到鄭明; 從日本人的殖民到終迎光復，哪知不久后卻迎來流亡者的暴政。

時過境遷，島嶼變天，經濟騰飛，百工繁絡。 日月蹉跎，過往竟似已成過眼雲煙。 如今臺灣正處於似乎無盡的混亂之中，小島被藍綠染色，繼而分裂臺灣眾生。 時代遷異，隨著美利堅合眾國陷入內戰，曾分隔了鄉愁的海峽中線隨著局勢而逐漸模糊。 歷史正逼著美麗島作出選擇。
是選擇擁抱這片土地，和過去道別？
還是重燃青天白日之志，重拾秋海棠葉之夢？
甚至最終歸向「人民共和國」的紅旗？
